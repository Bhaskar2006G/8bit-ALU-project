
# 8-bit ALU Design Using Verilog

## Project Description
Design and implementation of an 8-bit Arithmetic Logic Unit (ALU) using Verilog HDL.

## Operations
1. Addition
2. Subtraction
3. AND
4. OR
5. XOR

## Inputs
- A: 8-bit input
- B: 8-bit input
- Sel: 3-bit selector

## Outputs
- Result: 8-bit output
- CarryOut: Carry flag
- Zero: Zero flag

- Ubuntu
- Icarus Verilog
- GTKWave
- Git
- GitHub
